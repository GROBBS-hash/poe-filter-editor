# Map mod data from poe.re

`mapmods.json` (map mods and their short stash-search codes) and `trade_ids.json` (map mod → trade site stat id)
are generated data from [poe.re](https://poe.re) by Vegard Veiset (https://github.com/veiset/poe.re), used
under its data terms (fine for your own tools; credit poe.re; cache the files; send a User-Agent).
The game text belongs to Grinding Gear Games.

These copies are only a fallback: the app downloads the current files from https://data.poe.re
(once a day, User-Agent `poe-filter-editor/0.1 (local app)`) so they follow game patches.
